# Product family map

This is a clean-room roadmap based on the product families in the supplied Autodesk catalog. Product names below identify workflows the project aims to cover; Forge Studio does not contain Autodesk code, assets, or product branding.

| Forge workbench | Product families represented | Initial state |
| --- | --- | --- |
| Draft | AutoCAD, AutoCAD LT, AutoCAD Architecture/Electrical/Map 3D/Mechanical/MEP/Plant 3D/Raster Design, AutoCAD Web, DWG TrueView/TrueConvert, Design Review, DWF Writer, ObjectARX | 2D geometry editing, layers, project save, basic DXF import/export |
| Model | Fusion, Inventor, Alias AutoStudio/Concept/Design/SpeedForm/Surface, ReCap, Meshmixer, VRED, Tinkercad, EAGLE | Early parametric primitives, JSON projects, and box-mesh STL export |
| Build | Architecture, Engineering & Construction Collection, Revit, Revit LT, Revit LT Suite, Revit Live, Forma, FormIt, Advance Steel, Assemble, Navisworks, BIM Collaborate/Pro, Autodesk Docs/Build/Takeoff, BuildingConnected, Fabrication CADmep/CAMduct/ESTmep, Point Layout, Structural Bridge Design, Structural Analysis for Revit, Robot Structural Analysis, Vehicle Tracking, Plant Design Suite (discontinued) | Planned: building elements, schedules, coordination, and project information |
| Terrain | Civil 3D, InfraWorks, InfoDrainage, InfoWorks ICM/WS Pro, InfoWater Pro, Info360 Asset/Insight, Vehicle Tracking, Recap, ReCap Pro | Planned: terrain, alignments, drainage, networks, and asset workflows |
| Make | Fusion Additive Build/Generative Design/Machining/Nesting & Fabrication/Product Design/Simulation/Manage extensions, Inventor CAM/Nesting/Nastran, HSMWorks, FeatureCAM, PowerMill, PowerShape, PowerInspect, Factory Design Utilities, Moldflow Adviser/Communicator/Insight, Netfabb, Helius Composite/PFA, TruFiber/TruLaser/TruNest/TruPlan, Vault, CFD | Planned: manufacturing setup, toolpaths, simulation, and additive workflows |
| Motion | Maya, Maya LT, 3ds Max, MotionBuilder, Mudbox, Flame/Assist, Flare, Arnold, Lustre, VRED variants, Flow Capture/Production Tracking/Studio, FBX/Review, Media & Entertainment Collection | Planned: scenes, animation, compositing, rendering, and review workflows |
| Connect | Autodesk Platform Services, Autodesk Docs/Build, Fusion Team, BIM Collaborate/Pro, Vault Office/Professional, Flow Production Tracking, The Wild, Prospect, A360 | Planned: local project exchange and optional collaboration services |

Other catalog entries include collections, extensions, platform utilities, cloud services, education tools, and discontinued products. They should map to the closest workbench and remain separately identified by format, platform, eligibility, and lifecycle status where that affects the workflow.

Full compatibility and feature parity are long-term goals, not current capabilities.
